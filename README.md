## 📌 Sobre este repositório

Este repositório reúne minhas anotações, conceitos e aprendizados do **Google Data Analytics Professional Certificate** oferecido pela Google através da plataforma **Coursera**.

O objetivo é documentar minha jornada de aprendizado em análise de dados — desde os conceitos fundamentais até visualização e storytelling com dados.

---

## 🗺️ Trilha do Curso

O certificado é composto por **5 cursos principais**, cada um com seus próprios módulos:

| # | Curso | Tópicos Principais |
|---|-------|--------------------|
| 01 | [Introdução à Análise de Dados](./01-introducao/) | Processo analítico, ferramentas, SQL básico |
| 02 | [Faça Perguntas Para Tomar Decisões](./02-perguntas/) | Etapas de análise, planilhas, stakeholders |
| 03 | [Preparar Dados Para Exploração](./03-preparar-dados/) | Tipos de dados, bancos relacionais, metadados |
| 04 | [Analisar Dados Para Responder Perguntas](./04-analisar-dados/) | SQL avançado, agregação, validação |
| 05 | [Compartilhar Dados por Meio da Visualização](./05-visualizacao/) | Design, princípios visuais, correlação |
| 🗄️ | [Referência SQL](./sql/) | Todos os comandos SQL do curso em um só lugar |
| 🐍 | [Python](./python/) | Variáveis, funções, loops, estruturas de dados, POO |
| 📊 | [Tableau](./tableau/) | Visualizações, dashboards e storytelling com dados |

---

## 🧠 Conceitos-chave aprendidos

- **Processo de análise de dados:** Perguntar → Preparar → Processar → Analisar → Compartilhar → Agir
- **Ferramentas:** SQL, Google Sheets, Excel, Tableau
- **Boas práticas:** limpeza de dados, governança, segurança e ética
- **Visualização:** princípios de design, correlação vs. causalidade, storytelling
