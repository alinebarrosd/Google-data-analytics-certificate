# 02 — Faça Perguntas Para Tomar Decisões Baseadas em Dados

> **Plataforma:** Coursera · Google Data Analytics Certificate

## 🔍 As 6 Etapas em Detalhes

### Etapa 1 — Perguntar

Impossível resolver um problema sem saber qual é ele.

- Defina o problema que está tentando resolver
- Entenda completamente as expectativas das partes interessadas
- Foque no problema real, evitando distrações
- Colabore e mantenha comunicação aberta
- Veja toda a situação em seu contexto

> **Pergunte a si mesmo:** O que as partes interessadas dizem ser seus problemas? Como posso ajudá-las a resolvê-los?

---

### Etapa 2 — Preparar

Decida quais dados coletar e como organizá-los.

- Quais métricas medir?
- Onde localizar os dados?
- Como proteger esses dados?

---

### Etapa 3 — Processar

Dados limpos são os melhores dados.

- Usar funções de planilha para encontrar dados inseridos incorretamente
- Usar SQL para verificar espaços extras e entradas repetidas
- Verificar viés de dados

---

### Etapa 4 — Analisar

Pense de forma analítica sobre seus dados.

- Realizar cálculos
- Combinar dados de várias fontes
- Criar tabelas com os resultados

> **Pergunte:** Que história meus dados estão me contando?

---

### Etapa 5 — Compartilhar

Resuma seus resultados com visualizações claras e atraentes.

- Use gráficos e dashboards
- Adapte a comunicação para o público
- Garanta que suas descobertas levem a decisões mais informadas

---

### Etapa 6 — Agir

Coloque os insights em prática com recomendações baseadas em dados.

## 📊 Planilhas — Fundamentos

**Diferença entre fórmulas e funções:**
- **Fórmulas:** expressões criadas pelo usuário para realizar cálculos
- **Funções:** comandos pré-definidos que executam tarefas automaticamente

**Erros comuns em planilhas:**

| Erro | Causa |
|------|-------|
| `#DIV/0!` | Divisão por zero ou célula vazia |
| `#N/A` | Fórmula não encontra os dados referenciados |
| `#NAME?` | Nome de função escrito incorretamente |
| `#REF!` | Referência a uma célula inválida (ex: coluna deletada) |
| `#VALUE!` | Problema com tipo de dado (texto onde se espera número) |

## 👥 Stakeholders — Comunicação Eficaz

**Equipe executiva:** quer respostas diretas, não detalhes técnicos. Leve os insights principais primeiro; deixe detalhes no apêndice.

**Equipe voltada para o cliente:** tem seus próprios objetivos. Deixe os dados contarem a história — não se deixe influenciar para encontrar padrões que não existem.

**Equipe de ciência de dados:** parceiros técnicos; comunicação mais detalhada é bem-vinda.

### Boas práticas de visualização para stakeholders:

- Compare os **mesmos tipos de dados** para evitar confusão
- Defina o **eixo Y como 0** para mostrar a história completa
- Prefira **tabelas** quando o dado é simples — evite gráficos desnecessários
- **Teste a significância estatística** antes de afirmar que uma diferença é real
- Atenção ao **tamanho da amostra** — amostras pequenas distorcem resultados

## 🔑 Glossário

| Termo | Definição |
|-------|-----------|
| **Algoritmo** | Um processo ou conjunto de regras para uma tarefa específica |
| **Métrica** | Um tipo único e quantificável de dado usado para medição |
| **Meta métrica** | Uma meta mensurável avaliada por métricas |
| **ROI** | Fórmula que avalia o sucesso de um investimento usando métricas de lucro |
