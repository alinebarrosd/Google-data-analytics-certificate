## 👁️ Atributos de Pré-Atenção

São os elementos de uma visualização que as pessoas reconhecem **automaticamente e sem esforço consciente**.

Os blocos de construção essenciais são chamados de **Marcas** e **Canais**.

---

## ✏️ Marcas

Objetos visuais básicos como pontos, linhas e formas. Cada marca tem quatro qualidades:

| Qualidade | O que comunica | Exemplo de uso |
|-----------|----------------|----------------|
| **Posição** | Onde está no espaço em relação a uma escala | Comparar padrões de duas tendências |
| **Tamanho** | Quão grande, pequena, longa ou alta é | Transmitir relação entre categorias |
| **Forma** | O que o objeto representa | Barras no formato de pessoa para representar pessoas |
| **Cor** | Diferenciador de grupos ou conceitos | Lucrativo vs. não lucrativo; quente vs. frio |

> ⚠️ O olho humano pode interpretar comparações de tamanho involuntariamente — controle sempre a escala do seu visual.

---

## 📡 Canais

Aspectos visuais que representam características dos dados — são marcas especializadas para visualização.

Os canais variam em eficácia com base em três elementos:

| Elemento | Pergunta-chave |
|----------|----------------|
| **Precisão** | O canal permite estimar os valores com precisão? |
| **Popout** | É fácil distinguir determinados valores de outros? |
| **Agrupamento** | O canal comunica bem os grupos existentes nos dados? |

> 💡 Quanto mais você enfatiza uma única coisa, mais ela se destaca. A ênfase diminui a cada item adicionado — itens começam a competir entre si.

---

## 📊 Correlação vs. Causalidade

Dois conceitos frequentemente confundidos:

### Correlação
Mede o **grau em que duas variáveis se movem juntas**.

| Tipo | Descrição | Exemplo |
|------|-----------|---------|
| **Positiva** | Ambas sobem juntas | Temperatura alta → mais sorvetes vendidos |
| **Negativa** | Uma sobe, a outra desce | Mais exercício → menos peso |
| **Sem correlação** | Uma varia, a outra permanece igual | — |

> ⚠️ **Correlação não implica causalidade.** Duas variáveis podem se mover juntas por coincidência ou por um terceiro fator.

### Causalidade
Um evento **leva diretamente** a um resultado específico.

> Exemplo: o raio causa o trovão — o aquecimento e resfriamento do ar produz a onda sonora.

## 🎨 9 Princípios Básicos de Design

Diretrizes que analistas de dados devem considerar ao criar visualizações:

| # | Princípio | O que significa |
|---|-----------|-----------------|
| 1 | **Equilíbrio** | Distribuir cor e forma uniformemente — sem um lado que distraia o outro |
| 2 | **Ênfase** | Ter um ponto focal claro; o público deve saber onde se concentrar |
| 3 | **Movimento** | Guiar o olho do visualizador pela página com linhas e cores |
| 4 | **Padrão** | Usar elementos repetidos para criar consistência visual |
| 5 | **Repetição** | Reforçar o design repetindo elementos visuais |
| 6 | **Proporção** | Mostrar a importância relativa dos elementos pelo tamanho |
| 7 | **Ritmo** | Criar senso de movimento pelo espaçamento |
| 8 | **Variedade** | Usar elementos diferentes para gerar interesse |
| 9 | **Unidade** | Garantir que todos os elementos se complementam |

## ✅ Boas Práticas de Visualização

- **Compare os mesmos tipos de dados** — evite misturar métricas diferentes no mesmo gráfico
- **Defina o eixo Y como 0** — uma queda de 0,01% pode parecer enorme se você aproximar o zoom
- **Prefira tabelas simples** quando o dado é direto — evite gráficos desnecessários
- **Teste a significância estatística** antes de afirmar que uma diferença é real
- **Atenção ao tamanho da amostra** — amostras pequenas distorcem resultados

| Termo | Definição |
|-------|-----------|
| **Atributos pré-atentivos** | Elementos visuais reconhecidos sem esforço consciente |
| **Marcas** | Objetos visuais básicos (pontos, linhas, formas) |
| **Canais** | Aspectos visuais que representam características dos dados |
