## 📖 O que é Análise de Dados?

> *"The collection, transformation and organization of data in order to draw conclusions, make predictions, and drive informed decision-making."*

Empresas de todos os setores precisam de analistas qualificados para resolver problemas e tomar as melhores decisões possíveis.

---

## 🔄 As 6 Etapas do Processo de Análise de Dados

O ciclo completo que guia qualquer projeto de análise:

```
Perguntar → Preparar → Processar → Analisar → Compartilhar → Agir
```

| Etapa | O que fazer |
|-------|-------------|
| **Perguntar** | Entender o desafio; definir o problema com as partes interessadas |
| **Preparar** | Coletar e identificar fontes de dados; verificar precisão |
| **Processar** | Limpar e organizar os dados; remover inconsistências |
| **Analisar** | Calcular, identificar tendências e padrões |
| **Compartilhar** | Apresentar descobertas com visualizações claras |
| **Agir** | Colocar os insights em prática |

> ⚠️ O processo nem sempre é linear — você pode voltar a etapas anteriores conforme novas descobertas surgem.

---

## 🧰 Tipos de Dados

- **Numéricos:** valores que podem ser medidos ou usados em cálculos
- **De data:** representam um ponto no tempo; essenciais para rastrear tendências
- **Categóricos:** representam rótulos ou grupos discretos

---

## 🧠 Habilidades de um Analista de Dados

**Habilidades analíticas essenciais:**
- **Curiosidade** — desejo de aprender e buscar novos desafios
- **Compreensão de contexto** — entender as condições em que algo existe
- **Mentalidade técnica** — dividir tarefas em etapas menores e lógicas
- **Design de dados** — como as informações são organizadas
- **Estratégia de dados** — gestão de pessoas, processos e ferramentas

**Habilidades práticas:**
- Limpeza de dados
- Análise e extração de insights
- Visualização de dados
- SQL, R, Google Sheets, Tableau
- Pensamento crítico

---

## 🏗️ Ecossistema e Ciclo de Vida dos Dados

O **ecossistema de dados** é composto por elementos que interagem para produzir, gerenciar, armazenar, organizar, analisar e compartilhar dados.

**Ciclo de vida:**

| Fase | Descrição |
|------|-----------|
| Planejamento | Definir quais dados são necessários e como serão gerenciados |
| Captura | Coletar dados de diversas fontes |
| Gerenciamento | Armazenar, proteger e manter os dados |
| Análise | Usar os dados para resolver problemas e apoiar metas |
| Arquivamento | Guardar dados relevantes para referência futura |
| Destruição | Eliminar dados com segurança |

---

## 💡 Conceitos Importantes

- **Pensamento analítico:** identificar e definir um problema e sua solução usando dados
- **Tarefa de negócios:** a pergunta ou problema que a análise resolve para uma empresa
- **Imparcialidade:** qualidade da análise que não cria nem reforça viéses
- **Cientista de dados vs Analista:** cientistas criam novas perguntas; analistas respondem perguntas existentes

---

### Perguntas que um analista deve sempre se fazer:

1. Qual é a **causa raiz** do problema?
2. Onde estão as **lacunas** no processamento?
3. O que **não foi considerado** antes?
